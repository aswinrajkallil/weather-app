# 🌦️ Weather App

A modern and responsive Weather App built with React.js and OpenWeatherMap API.
Search any city worldwide and get real-time weather information instantly.

---

## 🚀 Features

* 🔍 Search weather by city name
* 🌡️ Real-time temperature updates
* 💧 Humidity information
* 💨 Wind speed details
* 🌤️ Dynamic weather icons
* 📱 Fully responsive UI
* ⚡ Fast API integration
* 🎨 Clean modern design

---

## 🛠️ Tech Stack

* React.js
* Vite
* CSS3
* OpenWeatherMap API
* React Icons

---

## 📦 Installation

Clone the repository:

```bash
git clone https://github.com/aswinrajkallil/weather-app.git
```

Navigate to project folder:

```bash
cd weather-app
```

Install dependencies:

```bash
npm install
```

Run development server:

```bash
npm run dev
```

---

## 🔑 Environment Variables

Create a `.env` file in the root directory:

```env
VITE_API_KEY=your_openweather_api_key
```

Get your free API key from:
https://openweathermap.org/api
